# Review selection

- **Title:** Review selection
- **Command:** `review-selection`
- **ChatGPT Canvas equivalent:** selecting a passage and asking for a revision

Select a passage in the editor before using it.

**Content** (paste into the prompt's content field):

```text
Look only at the passage I selected and propose up to 5 ways to improve it with suggest_edits, each with a short comment (what changes and why). Do not apply anything.
```
